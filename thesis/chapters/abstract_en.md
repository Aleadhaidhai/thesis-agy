# Abstract

Enterprise Instant Messaging (EIM) platforms capture valuable organizational knowledge across technical discussions, troubleshooting, and policy updates. However, EIM streams feature fragmented utterances, interleaved topics, multimodal attachments, temporal evolution, and strict conversation permissions. Generic RAG pipelines often suffer from broken semantic context, multimodal loss, and permission leakage risks. To enable privacy-preserving local deployment, this thesis designs and implements a multimodal knowledge retrieval Agent system for EIM.

For knowledge construction, a unified Multimodal Knowledge Unit (MKU) model converts images (OCR and vision-language descriptions), spreadsheets (row-level serialization), documents, and audio into indexable text. An online topic segmentation algorithm combining semantic similarity, reply/mention structure, and temporal decay disentangles interleaved chats into coherent topics, building summary-enhanced conversation units and context-injected attachment units with incremental updates. For retrieval, the system integrates dense vectors, BGE-M3 sparse weights, BM25, and Chinese-CLIP visual search via weighted RRF fusion, cross-encoder reranking, and time-decay scoring, enforcing conversation ACLs inside vector filtering with secondary checks. For question answering, a LangGraph Agent orchestrates query understanding, hybrid search, sufficiency reflection, citation-constrained generation, and sentence verification to return answers with clickable source cards.

All components run locally on standard CPU/MPS hardware without discrete GPUs via decoupled adapters. On SimEIM (946 messages, 24 attachments, 131 QA pairs) and C-MTEB T2Retrieval, topic segmentation reaches 0.571 Exact-F1 and 0.848 one-to-one overlap; reranked hybrid retrieval achieves 0.956 Hit@1 on SimEIM and 0.9272 nDCG@10 (0.9150 Recall@10) on T2Retrieval; and the Agent outperforms NaiveRAG on text (0.914 vs. 0.837), document (0.929 vs. 0.893), and multi-hop queries (0.700 vs. 0.600), reaching 0.917 unanswerable refusal with zero leakage. All ten functional tests passed.

**Keywords**: Enterprise Instant Messaging; Multimodal Knowledge Retrieval; Topic Segmentation; Hybrid Retrieval; LLM Agent
