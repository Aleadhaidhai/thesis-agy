# 摘要

企业即时通讯平台承载了研发讨论、故障排查、规范同步与项目协作等大量组织隐性知识。然而，企业聊天消息普遍存在短文本、话题交织、附件模态多样、新旧结论演化以及群聊权限边界严格等特点，通用检索增强生成方案直接应用于该场景时面临语义割裂、多模态信息丢失和越权泄露等问题。针对上述挑战，本文面向企业私有化轻量部署需求，设计并实现了一套企业即时通讯多模态知识检索 Agent 系统。

在知识构建层面，系统提出统一的多模态知识单元模型，通过 OCR 与视觉语言模型互补的图片转写、表格行级序列化和结构感知的文档与语音解析消除模态差异；提出融合语义相似度、回复与提及结构及时间衰减的在线话题切分算法，将交织消息流解缠为连贯话题，并据此构建摘要增强会话单元与上下文注入附件单元，支持增量回溯更新。在混合检索层面，融合稠密语义、BGE-M3 稀疏词汇权重、BM25 词法与视觉跨模态多路召回，结合加权倒数排名融合、交叉编码器重排和时效衰减排序，并将基于群成员关系的访问控制列表下推至向量检索底层以实现权限隔离。在智能体问答层面，基于状态图构建涵盖查询理解、混合检索、充分性反思、引用约束生成与句证一致性校验的闭环推理流程，输出附带可点击溯源卡片的回答。

系统全部组件采用开源模型在单机本地部署运行，并通过解耦的即时通讯适配器接口与自研模拟器完成功能集成。实验结果表明：在线话题切分在模拟企业数据集 SimEIM 上的准确匹配 F1 与 1-1 重叠率分别达 0.571 与 0.848，显著优于时间间隔与固定窗口基线；融合重排检索在 SimEIM 上的首位命中率达 0.956，在公开中文基准 T2Retrieval 上取得 0.9272 的 nDCG@10 与 0.9150 的 Recall@10；端到端智能体将文本、文档及多跳问答准确率较常规检索基线分别提升至 0.914、0.929 与 0.700，无答案拒答率提升至 0.917 且权限泄露率为零，10 项系统功能验收测试用例全部通过。

**关键词**：企业即时通讯；多模态知识检索；话题切分；混合检索；大模型智能体
